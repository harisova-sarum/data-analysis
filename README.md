# Data Analysis: тренировочные проекты по машинному обучению

Набор упражнений на Python по основным алгоритмам классического машинного обучения и обработке данных с использованием pandas и scikit-learn.

## Что внутри

- **pandas** — коллекция упражнений на **15 разных датасетах**: Ирисы, Титаник, Герои Dota, Такси, Заказы, Клиенты, Компании, Зарплата, Работа с датами, Геномные расстояния между видами, Водоросли, Успеваемость студентов и другие. Практика по очистке, фильтрации, группировке и агрегации разнородных реальных данных
- **Преобработка/Студенты** — подготовка данных к обучению моделей (работа с пропусками, кодирование признаков, нормализация)
- **LinearRegression/Студенты** — линейная регрессия
- **KNeighborsClassifier/Студенты** — классификация методом k ближайших соседей
- **DecisionTreeClassifier** — классификация деревом решений, отработана на 4 датасетах: Ирисы, Котики-собачки, Студенты, Титаник
- **RandomForestClassifier (вероятность)/Студенты** — классификация случайным лесом с оценкой вероятностей
- **KMeans (класстеризация)/Студенты** — кластеризация методом K-средних

Часть упражнений (LinearRegression, KNeighborsClassifier, RandomForestClassifier, KMeans, Преобработка) выполнена на одном учебном датасете «Студенты» — практика последовательного применения разных алгоритмов к одному и тому же набору данных, что позволяет сравнивать подходы между собой. pandas и DecisionTreeClassifier отработаны на более широком наборе датасетов.
